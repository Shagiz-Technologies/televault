# Code of Conduct

TeleVault welcomes contributors who communicate respectfully and focus on practical, safe improvements.

## Expected behavior

- Be respectful and constructive.
- Discuss technical tradeoffs with evidence.
- Protect user privacy and avoid sharing sensitive data.
- Keep issues and pull requests focused.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Publishing private user data, secrets, credentials, or exploit details.
- Repeated off-topic disruption.

## Enforcement

Project maintainers may remove comments, close issues, restrict participation, or report abuse when needed to keep the project safe and productive.
