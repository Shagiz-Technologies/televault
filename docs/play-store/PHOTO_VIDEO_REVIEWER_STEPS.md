# Photo and Video Permission Reviewer Steps

1. Install and open TeleVault on Android 14 or later.
2. Connect the provided Telegram review account and create or select a private
   backup bucket.
3. Open Library. Observe the in-context explanation before Android's media
   permission dialog.
4. Choose full access. Confirm Library displays accessible photos and videos.
5. Enable Auto Backup in Sync Preferences, add a new demo photo, and confirm it
   appears in Library and the backup queue without manual picker interaction.
6. In Android Settings, change TeleVault to selected-media access.
7. Return to Library. Confirm the persistent limited-access banner appears and
   only selected demo media is shown.
8. Open Settings > Media Access. Confirm scope is Limited, discovery is Partial,
   and the accessible item count is shown.
9. Use Manage/Update selected media and select another demo item.
10. Confirm the new selection appears and no existing remote Telegram backup is
    deleted when local access is reduced.
11. Deny media access. Confirm TeleVault remains usable for Settings and recovery
    and does not open Android Settings automatically.

Use demo media and review credentials only. Do not expose a personal Telegram
account or personal gallery in the review recording.
