# Photo and Video Declaration Video Script

Target length: 60-90 seconds. Record on Android 14+ using demo data.

1. Open TeleVault and show Library's explanation: continuous access discovers
   new gallery items for automatic backup.
2. Tap Continue and choose full photo/video access in Android's dialog.
3. Show demo media in Library, then show Auto Backup enabled for the active
   bucket.
4. Add a new demo photo and show it entering the backup queue automatically,
   without opening a picker.
5. Change Android media permission to selected access and return to TeleVault.
6. Show the limited-access banner and Settings > Media Access reporting Partial.
7. Tap Update selected media and add another demo item.
8. End on the Sync Dashboard and state that totals cover accessible media only;
   remote Telegram backups are retained when local access changes.

Do not show real media, phone numbers, usernames, channel identifiers,
notifications, credentials, OTPs, or local paths.
