# Support

The canonical consumer-facing support page is:

<https://shagiz-technologies.github.io/tele-vault/support.html>

This file describes support intake for contributors and source builds.

## Application bugs

Use [GitHub Issues](https://github.com/Shagiz-Technologies/televault/issues/new/choose)
for reproducible TeleVault bugs. Include the app version or commit, Android
version, device model, install source, reproduction steps, expected behavior,
and sanitized logs.

## Feature requests

Describe the user problem and expected outcome. Changes involving architecture,
permissions, encryption, Telegram login, synchronization, restore, storage
format, or dependencies require maintainer agreement before implementation.

Never publish phone numbers, login codes, Telegram credentials or sessions,
personal media, metadata backups, databases, signing material, private paths,
unredacted logs, or exploit details.

## Telegram account support

TeleVault cannot recover Telegram accounts, deliver login codes, reverse
restrictions, or resolve Telegram service outages. Use
[Telegram Support](https://telegram.org/support) for those problems.

Support is best-effort and is not guaranteed.
