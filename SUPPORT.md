# TeleVault Support

TeleVault is an independently maintained open-source project. Support is
best-effort and is not guaranteed.

## Reproducible bugs

Use the repository's
[bug report form](https://github.com/Shagiz-Technologies/televault/issues/new?template=bug_report.yml)
for reproducible TeleVault problems. Search existing issues first and include
the app version, source commit when applicable, Android version, device model,
installation source, reproduction steps, and sanitized logs.

GitHub Issues are not Telegram customer support. Questions about Telegram
accounts, Telegram service availability, account restrictions, or Telegram
policies should use Telegram's own support channels.

## Feature proposals

Use the
[feature request form](https://github.com/Shagiz-Technologies/televault/issues/new?template=feature_request.yml)
with a clear user problem and desired outcome. Changes involving architecture,
permissions, encryption, login, sync, restore, storage formats, native
binaries, or dependencies require maintainer agreement before implementation.

## Security reports

Use
[GitHub Private Vulnerability Reporting](https://github.com/Shagiz-Technologies/televault/security/advisories/new)
for vulnerabilities. Do not publish exploit details or sensitive information
in a public issue. See [`SECURITY.md`](SECURITY.md).

## Protect personal information

Never post:

- Telegram API credentials, phone numbers, authorization codes, or session
  files.
- Personal photos, videos, contacts, channel identifiers, or profile details.
- Metadata snapshots, local databases, private file paths, or unredacted logs.
- Keystores, signing credentials, service-account files, or private keys.

Maintainers may close or redact reports that expose private information.
